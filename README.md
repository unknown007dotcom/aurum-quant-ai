# XAUUSD Bank Algorithm Analyzer

Local static web app for analyzing live `XAU/USD` market structure with:

- SMA 20 / SMA 50 bias
- FVG detection
- Order Blocks (extreme and decisional)
- BOS and CHoCH
- Midnight line bias
- Unmitigated OB reversal zone detection
- Rule-engine trade decision
- AI explanation through NVIDIA's OpenAI-compatible endpoint

## Run

This build should be run through the local server so the `/api/*` routes are available.

```powershell
node server.js
```

Then open `http://localhost:3000`.

## Chat Mode

Open **Chat Mode** beside **Settings** in the terminal header, or visit `/chat.html`.
The dedicated workspace has searchable, browser-local conversations on the left,
a central chat composer, and model/response settings plus a custom image area on
the right. On smaller screens the sidebars become keyboard-accessible drawers.

Your assistant **Mira** has a default anime portrait in the right panel.
You can also upload a PNG, JPEG, or WebP and restore Mira's portrait at any time; it stays in this browser and is not sent
to the AI. Chat requests use the existing NVIDIA configuration through the
same-origin `/api/chat` endpoint, independently of trade execution. For gold questions,
Mira can use server-fetched, read-only OANDA XAU/USD quotes and recent M15/H1
candles. Answers show source timestamps; stale or closed-market quotes are not
presented as live. The per-conversation market-context switch disables these
lookups without changing the broker or trading settings.
See [market-context integration](docs/chat-market-context.md).

Run `npm test` for the analysis-engine and chat tests. See
[Chat Mode implementation notes](docs/chat-mode.md) for API and storage details.

## AI backend and deployment checks

Chat Mode, terminal AI analysis, and AI health use the same-origin Vercel API and
shared NVIDIA runtime. Market data and trading controls retain their existing
Cloudflare backend. Set a permanent `NVIDIA_API_KEY` in the server environment
(it overrides older stored model keys); never commit it or paste it into source.

- `npm test`: analysis, chat, provider, and configuration regression tests.
- `npm run test:ai-ui`: verifies the terminal sends AI requests to the correct
  backend without browser-stored credentials or trading commands.
- `npm run build:vercel`: creates an allowlisted static site and private API function.
- Set `AURUM_VERIFY_LIVE_AI=1` for a release build that must receive genuine chat
  and structured-analysis replies before the deployment can succeed. The probes
  use synthetic text without live market prices and never place orders.

See [AI diagnostic findings](docs/ai-diagnostics.md) for the repaired failure modes
and credential-rotation requirements.
